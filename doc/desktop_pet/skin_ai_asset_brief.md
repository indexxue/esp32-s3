# 桌宠皮肤 — 生图自动化任务（直接复制）

上传参考图后，把下面「任务正文」整段复制给生图 AI。  
它应按步骤自动出完全部图，你只需收图验收。

**五官位置与旋转不在本任务内**：由本地 `pet_skin` 工具标定（预留）。固件本阶段不叠五官，生图只需无脸透明身体。

---

## 任务正文（复制从此处开始）

```
# 自动化任务：桌宠无脸身体皮肤包

你是桌宠皮肤批量出图代理。用户已上传【唯一参考图】。请按本任务自动跑完全流程，不要等我逐张确认（除非某张自检失败需要重出）。

## 0. 角色锁定（先做，只输出文字确认）

根据参考图，用 1～2 句话锁定并回复：
- 物种 / 体型
- 主色与材质（毛/壳/布等）
- 风格（保持参考；可轻微 Q 版，禁止换物种）

之后所有图必须服从此锁定。

## 1. 全局硬规则（每张都遵守）

1. 输出 PNG，RGBA 真透明底；禁止白底、灰底、棋盘格烘焙进像素。
2. 严禁绘制：眼睛、瞳孔、睫毛、眉毛、嘴巴、牙齿、舌头表情。（五官由程序叠加；位置与旋转由用户工具标定，你不要输出坐标。）
3. 无文字、无水印、无地面、无阴影道具、无第二角色。
4. 身体帧画布固定 160×160 像素；splash 固定 240×240 像素。
5. 有效内容落在约直径 140 的圆内（圆屏会切角）。
6. 头部/脸所在表面只留皮毛或外壳，不画五官。姿势可自由（站、歪、躺、趴），头可以在画面左侧或下方；不要为「迁就固定五官」而把所有动作都画成脸朝正中。
7. 同一包多帧：尽量脚底或身体重心对齐、比例一致、配色一致、光照方向一致。
8. 边缘抗锯齿干净；角色内部避免接近 #202020 的填充色。
9. 每张单独一张图；文件名必须与清单完全一致。
10. 不要输出五官坐标或旋转角。

## 2. 执行顺序（严格按序，完成一张再下一张）

对每一张：生成 → 按 §3 自检 → 通过则交付该文件名 → 再做下一张。  
自检失败：同规则重出该帧，最多 2 次；仍失败则标注「需人工」并继续下一张。

### 清单

| 序号 | 文件名 | 尺寸 | 动作要求 |
|------|--------|------|----------|
| 1 | idle_0.png | 160 | 标准站姿，正面或微 3/4，重心稳 |
| 2 | idle_1.png | 160 | 与 idle_0 相同，仅整体上移或下移约 1～2px（呼吸），对齐基准与 idle_0 一致 |
| 3 | sleepy.png | 160 | 略下沉、没精打采，无五官 |
| 4 | sad.png | 160 | 垂头、肩垮，无五官 |
| 5 | eat_0.png | 160 | 前倾，准备吃 |
| 6 | eat_1.png | 160 | 咀嚼/吞咽姿态（身体动作表达，仍不画嘴） |
| 7 | play_0.png | 160 | 蹦起或向一侧歪身 |
| 8 | play_1.png | 160 | 落地或向另一侧晃，与 play_0 成对 |
| 9 | poke.png | 160 | 被点触：轻微挤压或后仰 |
| 10 | sleep_loop.png | 160 | 蜷睡、侧躺或趴下均可；头可偏左/偏下 |
| 11 | splash.png | 240 | 以 idle 全身为准，居中放大适配 240 画布，外侧全透明 |

不要生成：Dock 图标、眨眼图、带完整五官的整宠插画、开机动画序列、锚点标注图。

## 3. 每张自检清单（交付前默默执行）

- [ ] 尺寸正确（160 或 240）
- [ ] 背景真透明
- [ ] 无眼/嘴/眉
- [ ] 与参考同一角色（色/形未漂）
- [ ] 站立类帧与 idle_0 对齐大致稳定（sleep 姿势可例外）
- [ ] 缩略到很小仍能认出是参考角色

## 4. 交付格式

- 按序号 1→11 依次给出图片。
- 每张标注文件名。
- 全部完成后输出简短清单：
  已完成：…
  需人工：…（若无则写无）

## 5. 最终成品应是什么样（验收标准）

用户收到的应是一套「无脸剪贴画身体」：

- 每张只有角色外形，四周全透，像贴纸。
- 脸上没有五官；之后用户在皮肤工具里为每帧标定眼/嘴/眉的位置，且每个五官可单独旋转。
- 11 张是同一只宠的不同姿势（站、蔫、吃、玩、戳、睡 + 开机），不是换角色。
- idle_0 / idle_1 几乎一样，仅轻微起伏。
- splash 更大、更干净，像开机时的角色剪影。
- 睡姿允许头在侧面或下方，不必强行脸居中。

现在开始：先输出 §0 角色锁定，然后从 idle_0.png 自动做到 splash.png。
```

## 你收到图后怎么用（给人看，不用复制给生图 AI）

1. 把 PNG 放进 `tools/pet_skin/assets/`（文件名保持上表不变），或 GUI **Import folder…**。
2. **Bind assets/** → 圆屏预览各 clip → **Build pack + splash**。
3. 拷 `tools/pet_sim/sdcard/` 到设备 `/sdcard/`（含根目录 `config` 与 `pet/`）。

固件本阶段不叠五官，预览也不必开锚点。逐步说明见 [`tools/pet_skin/README.md`](../../tools/pet_skin/README.md)。

约定详情：[`framework.md`](framework.md) §6 · [`product.md`](product.md) §A / §B.3。
