# 桌宠皮肤 — 独立生图任务（按条复制）

上传**一张带角色（可含五官）的参考图**后，**每次只复制下面「一条」任务**发给生图 AI（不要一次丢整张表）。  
做完一张、收下文件，再发下一条。

设备：**240×240 圆屏**。身体帧 **160×160**，splash **240×240**。四角会被切掉。

共用规则（每条任务开头已带，一般不用另发）：
- PNG，RGBA 真透明底
- 跟参考同一角色（可含五官）
- 角色居中，落在安全圆内（身体约 ø140；splash 约 ø200）；四角勿放耳/尾
- 无字、无水印、无地面、无第二角色

收图后：放入 `tools/pet_tool/skin/assets/` → Bind → Build。  
详见 [`tools/pet_tool/skin/README.md`](../../tools/pet_tool/skin/README.md)。
