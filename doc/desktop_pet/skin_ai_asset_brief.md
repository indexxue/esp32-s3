# 桌宠皮肤 — 按动作类型生图（每类单独发送）

上传**一张带角色（可含五官）的参考图**后：  
**每次只复制下面「一类」任务**发给生图 AI（一类 = 同一动作的 4～8 张连贯帧）。  
做完一类、收下文件，再发下一类。

设备：**240×240 圆屏**（设备会切掉四角）。身体帧 **160×160**，splash **240×240**。

为何按类合并：同一提示里一次出多帧，角色比例/五官/色调更稳。

收图后：若是「一张拼了多格」且背景不透明，先用 **「拆格抠图」**；再放入 `tools/pet_tool/skin/assets/` → Bind → Build。

---

## 强制硬规则（必读；已写入各类任务）

生图时**必须**遵守；违反即作废重出：

| 必须 | 禁止 |
|------|------|
| **全身入画**：从头（含耳）到脚（含尾/手脚）完整可见，略留边 | **半身、大头特写、裁掉脚/耳/尾** |
| **方形画布贴纸**：角色直接画在透明/纯色平面上 | **圆形相框、圆边裁切、圆形遮罩、圆洞、圆贴片、圆环装饰** |
| 真透明底或后期可抠的纯色底 | 把「圆屏」画成画面里的圆框 |
| 角色居中，略缩小，四周留空 | 贴边、顶天立地顶满画布 |

说明：「安全圆」= 给**真机圆屏切角**留的**想象边界**，**不要画出来**。

## 拆格抠图（整图 → 多张透明小图，复制给另一个 AI）

```
我上传了一张「桌宠皮肤拼版图」：同一角色的多格小图排在一张图里（常见 2×3=6 格）。

请你完成：

1) 按从左到右、从上到下，把每一格裁成独立图片。
2) 去掉背景：输出真正 RGBA 透明底 PNG（alpha=0）。不要白底/灰底/棋盘格；不要残留色边。
3) 若原格里有圆形边框、圆遮罩、圆环、圆角相框：必须去掉，只保留角色本体，不要圆形轮廓线。
4) 每张正好 160×160：角色全身完整缩放进画布（contain 居中），头到脚都在画面内，外侧透明；禁止拉伸变形、禁止裁成半身。
5) 不要添加文字、水印、边框、序号、圆形装饰。
6) 不要改角色长相/配色；只做分格 + 去圆框 + 抠底 + 统一画布。

输出文件名（按格顺序）：
sad_0.png
sad_1.png
sad_2.png
sad_3.png
sad_4.png
sad_5.png

（把前缀 sad 改成实际 clip：idle/eat/play/…；有几格就编到 _(N-1)。）

请交付分离后的各张 PNG，不要再合成拼版。
```

## 0. 角色锁定（先发，只要文字）

```

不要出图。之后所有皮肤图必须跟这只宠一致。
```

## 1. idle（呼吸循环）— 4～8 张

```
【桌宠贴纸帧 · idle】参考我上传的图，一次生成 6 张独立方形 PNG（可 4～8，连续编号）。

强制要求（违反重出）：
1. 文件名：idle_0.png … idle_5.png
2. 每张 160×160，RGBA 真透明底（或纯色底后期可抠）。
3. 必须是「全身贴纸」：从头（含耳朵）到脚完整可见，含尾/手脚；禁止半身、大头特写、缺脚。
4. 禁止出现任何圆形：禁止圆框、圆遮罩、圆边裁切、圆环、圆形底板、圆贴片。画布是正方形；角色直接立在透明上，像剪纸贴纸，不是圆洞里的肖像。
5. 角色居中并略缩小，四周留空；不要贴满画布边缘。
6. 内容：标准站姿，正面或微 3/4；各帧几乎相同，仅整体上下约 1～2px 呼吸；比例/五官/色调/脚底全帧一致。
7. 无字、无水印、无地面、无第二角色、无视频。

只出这一组 idle。
```
